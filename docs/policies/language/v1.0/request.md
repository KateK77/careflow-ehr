# Approved language-policy request

**Historical Documentation and Language Policy**

1. Preserve all original Phase 0 requirements and documents, including those written in Chinese, as immutable historical records. Do not delete, overwrite, or rewrite them.
2. Create and maintain professional English versions of the requirements for all future development, using the original documents as the source of truth.
3. All new GitHub Issues, Pull Requests, commit messages, technical documentation, development reports, and acceptance records must be written in English.
4. When user feedback or instructions are provided in Chinese, translate them accurately into professional English for GitHub documentation.
5. Preserve original approved prompts verbatim for traceability. If a prompt is in Chinese, retain the original and provide a separate English translation.
6. Keep the original documents and their English translations clearly linked, with explicit version numbers.
7. Update AGENTS.md to make these language conventions mandatory for future development.
8. Do not modify existing application functionality solely to implement this documentation policy.
