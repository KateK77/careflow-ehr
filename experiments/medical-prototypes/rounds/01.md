# 第 1 轮 · 可运行基线

生成描述：以 OpenEvidence、MyChart 和 PubMed 的公开核心流程为参考，同轮生成三个可独立打开的浏览器原型。OpenEvidence 原型展示按主题检索的预写摘要和 PubMed 引用。MyChart 原型提供虚构患者的检验结果、模拟预约和消息。PubMed 原型支持样本文献搜索、筛选和收藏。三个原型都可以离线体验，原始文献链接需要联网。

| 原型 | 本轮体验任务 |
| --- | --- |
| OpenEvidence | 运行 DAPA-CKD 示例并打开引用。再输入一个样本库之外的问题。 |
| MyChart | 展开检验结果，预约一次并刷新，随后取消。保存一条虚构消息。 |
| PubMed | 搜索 semaglutide，再选 Review 和 2025。收藏匹配的文章并打开收藏列表。 |

首轮补充：证据问答加入可重用的提问历史。患者门户加入健康摘要、模拟续药和账单支付。文献检索加入字段筛选、日期排序、收藏导出和跳转到真实 PubMed 检索。

反馈：待你体验。请记录软件、操作步骤、实际结果和希望下一轮达到的效果。
