# Round 1 — Initial Prototypes

## Generation prompt

Build three independently accessible browser prototypes based on the public workflows of OpenEvidence, MyChart, and PubMed. Use a fixed study library for evidence summaries and citations, a fictional patient record for the portal, and a small article index for literature search. Support offline use for the demo workflows. External article links and full PubMed search require internet access.

| Prototype | Implemented workflows | Try it |
| --- | --- | --- |
| OpenEvidence | Topic matching, prepared evidence summaries, PubMed citations, reusable question history | Run the DAPA-CKD example, open its citation, and try a question outside the sample library. |
| MyChart | Test results, health summary, appointments, local messages, mock refill requests, and simulated payments | Open a test result, book a visit, refresh, and cancel it. Save a fictional message and record a mock refill request. |
| PubMed | Keyword and field search, year and publication type filters, date sorting, bookmarks, PMID export, and a link to the equivalent PubMed search | Search for semaglutide, select Review and 2025, save the matching article, and export its PMID. |

## User feedback

Round 1 is ready for review. For any issue or change, record the app, steps, actual behavior, and expected behavior. Round 2 begins for each app after the user shares feedback.
